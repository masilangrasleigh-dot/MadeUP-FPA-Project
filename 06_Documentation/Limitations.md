# 116. Limitations Document

**Document:** MadeUP FP&A Analytics Project — Scope & Limitations  
**Scope:** Transparent disclosure of project boundaries, synthetic data nature, and methodological simplifications to ensure professional clarity and prevent misleading claims.

---

> This project uses synthetic data and is intended for educational and portfolio purposes.
> 
> The financial results do not represent a real company.
> 
> Budget and forecast assumptions are analyst-developed.

---

> The project does not represent confidential corporate financial information.
> 
> Forecasting methodology is intentionally simplified to demonstrate core FP&A concepts rather than replicate a production forecasting system.

---

## Purpose & Governance

* **Professional Transparency**: Clearly outlining these boundaries ensures that all stakeholders, reviewers, and portfolio evaluators understand the structural nature of the dataset and modeling framework.
* **Educational Scope**: Designed to showcase end-to-end Financial Planning & Analysis (FP&A) competencies, covering relational SQL schemas, advanced Excel modeling, automated checks, scenario sensitivity analysis, and Power BI visualization.
