# 114. Data Dictionary

**Document:** MadeUP FP&A Analytics Project — Master Data Dictionary  
**Scope:** Comprehensive schema definition for relational SQL tables, Excel financial models, and Power BI semantic layers.

---

## Core Data Dictionary

| Field | Description | Source | Type |
| :--- | :--- | :--- | :--- |
| **MonthStart** | Reporting month (start date of financial period) | SQL / Excel | Date |
| **ProductID** | Unique product identifier (e.g., P001, P002) | SQL / Excel | Text |
| **ProductName** | Commercial name of the product or service | SQL / Excel | Text |
| **BusinessUnit** | Operating business unit (Devices, Cloud & Software, Digital Services) | SQL / Excel | Text |
| **RevenueModel** | Pricing mechanism (Unit Sales, Subscription, Transactional/ARPU) | SQL / Excel | Text |
| **BasePrice** | Base catalog price or unit selling price | SQL / Excel | Decimal / Currency |
| **COGSRate** | Cost of Goods Sold percentage rate relative to revenue | SQL / Excel | Decimal (Percentage) |
| **RegionID** | Unique geographic region identifier (R01 to R04) | SQL / Excel | Text |
| **RegionName** | Descriptive name of the geographic market | SQL / Excel | Text |
| **RegionFactor** | Regional economic and volume scale adjustment factor | SQL / Excel | Decimal |
| **Revenue** | Total gross revenue generated by product and region | SQL / Excel | Decimal / Currency |
| **COGS** | Direct Cost of Goods Sold associated with product delivery | SQL / Excel | Decimal / Currency |
| **DepartmentID** | Unique organizational department identifier (D01 to D08) | SQL / Excel | Text |
| **DepartmentName** | Descriptive department name (Sales, Marketing, R&D, G&A, IT, etc.) | SQL / Excel | Text |

| **Units** | Sales volume quantity sold | SQL / Excel | Integer |
| **ASP** | Average Selling Price per unit | SQL / Excel | Decimal / Currency |

---

## Entity-Relationship & Schema Notes

1. **Star Schema Architecture**: The relational data warehouse is modeled using a central fact-and-dimension architecture. Fact tables (`Actual Revenue`, `Actual Opex`, `Actual Headcount`) link to master dimension tables (`Products`, `Regions`, `Departments`, `Expense Category`) via respective primary keys (`ProductID`, `RegionID`, `DepartmentID`, `ExpenseCategoryID`).
2. **Data Integrity & Version Control**: All calculations in the Excel FP&A model (`MadeUP_FPA_Model.xlsx`) reference these standard schema definitions and are validated via automated control checks (`11_Checks`).
